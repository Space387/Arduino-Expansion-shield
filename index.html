Nano CANBus Expansion Shield

Build guide for the V3 expansion board — Arduino Nano R4 with native CAN, distributed I/O for Megasquirt

Overview Bill of Materials Parts by Connector Group Assembly Connector Pinout

Overview

The Nano CANBus Expansion Shield is a distributed I/O board for the C4 Corvette's CAN bus architecture. It mounts an Arduino Nano R4 (native CAN controller) and breaks out analog inputs, high-current PWM outputs, low-current switches, optoisolated inputs, and CAN bus through a sealed 26-pin TE SuperSeal connector. The board communicates with the Megasquirt ECU over CAN at 500 kbps.

Key Features

  • 8 analog input channels with optional 4.7kΩ pullup and 0.1µF filtering per channel
  • 4 high-current PWM outputs via IRLZ44N MOSFETs (fans, pumps, relays)
  • 4 low-current switch outputs via BS170 MOSFETs
  • 2 optoisolated digital inputs via PC817 optocouplers
  • Native CAN bus (Nano R4) with 120Ω termination option
  • Buck converter for 5V regulation from 12V vehicle power
  • Sealed 26-pin TE SuperSeal connector for engine bay environments

Assembly Instructions

General guidance for through-hole assembly. Verify component placement against your KiCad layout and silkscreen markings before soldering.

1. Resistors and Diodes (lowest profile first)

  • R1–R8 (4.7kΩ) — Install only for channels using unpowered sensors. For powered sensors (e.g. TPS), leave open. See note above.
  • R9–R16, R25–R26 (1kΩ) — Gate resistors for MOSFETs and current-limiting for optocoupler inputs. Install all.
  • R17–R24, R27–R28 (10kΩ) — Gate pull-downs and opto output pull-downs. Install all.
  • R29 (120Ω) — CAN bus termination. Install only if this board is the furthest node from the ECU.
  • D1–D4 (1N5819) — Schottky flyback diodes for IRLZ44N outputs. Install all. Observe polarity (cathode stripe toward load).
  • D5–D8 (1N4148) — Signal diodes for BS170 outputs. Install all. Observe polarity (cathode stripe).

2. Capacitors

  • C1–C8, C10 (0.1µF ceramic) — Input filter caps for analog channels and CAN transceiver decoupling. Non-polarized.
  • C9 (220µF hybrid polymer) — Power supply filter. Observe polarity — the negative terminal is marked. Install on the buck converter input side.

3. Semiconductors (note orientation)

  • U2, U3 (PC817 optocouplers, 4-DIP) — Align pin 1 (notch/dot) with silkscreen. The opto must be mounted on the component side of the board — confirm you're not reading the KiCad layout mirrored. Pin 1 is the anode (input+), pin 2 is cathode (input-), pin 3 is emitter (output), pin 4 is collector (output). Isolation depends on correct grounding: pin 2 (input ground) goes to power ground, not sensor ground.
  • Q5–Q8 (BS170, TO-92) — Orient per silkscreen. Pinout: D, G, S (left to right, flat side facing you). Verify against your layout.
  • Q1–Q4 (IRLZ44N, TO-220) — Mount with heatsink tab oriented per silkscreen. These are the high-current drivers — ensure good solder fillets on the drain and source pins. Pinout: G, D, S (left to right, tab facing you).
Optoisolator grounding: The PC817 input ground (pin 2) must connect to power ground, not sensor ground. If pin 2 is tied to sensor ground, the isolation is defeated — 12V transients get a return path through the Nano. Verify this on your assembled board.

4. Power and CAN

  • U1 (Buck converter) — Install per module orientation. Input is 12V from the connector (pin 5), output is 5V to the Nano and 5VREF pin (pin 12). C9 (220µF) is the input filter.
  • J4 (CAN transceiver) — Interface between the Nano's native CAN (D4/D5) and the physical bus (CAN H on pin 16, CAN L on pin 10). C10 (0.1µF) is decoupling. R29 (120Ω) goes across CAN H/L — only if terminating.

5. Connectors

  • J1 (6473423-1, SuperSeal R/A PCB header) — Solder the 26 through-hole pins. The right-angle body should sit flush against the board.
  • J2, J3 (if populated) — Auxiliary analog and digital headers. Optional — populate if you need debug/breakout access.

6. Arduino Nano R4

  • Install via male/female headers or direct solder. If using female headers, the Nano can be removed for programming. If direct-soldered, program via the USB connector before final enclosure installation.
  • The Nano R4's native CAN controller uses D4 (CTX) and D5 (CRX). These are not broken out to the SuperSeal — they connect internally to J4 (transceiver).

7. Harness Assembly

  • Crimp socket contacts (3-1447221-3) onto 16-18AWG wires using a proper ratcheting crimp tool.
  • Insert contacts into the SuperSeal plug housing (1473416-1) until they click. Pull gently to confirm retention.
  • Install cavity plugs (4-1437284-3) into any unused connector positions to maintain the IP67 seal.
  • Route CAN H and CAN L as a twisted pair (minimum 1 twist per inch) for noise immunity.
