Nano CANBus Expansion Shield — Build Guide

Arduino Nano R4 shield for building custom vehicle controller nodes on a Megasquirt CAN bus. Uses the Nano's native CAN controller at 500 kbps — no external CAN chip required.

R1–R8 (4.7kΩ) are optional. Install only when the corresponding input is used with an unpowered sensor (1- or 2-wire temperature sensor, thermistor). If the slot is used with a powered sensor that has its own 5V supply, signal, and ground (e.g. TPS), omit the resistor for that channel.
R29 (120Ω) is conditional. Install only if this module is the furthest node from the ECU on the CAN bus — i.e. it's a bus endpoint. If it's a mid-bus node, omit R29.

SuperSeal 1.0 Connector — 26-Position, 4-Row, 3-Key

The board uses a TE SuperSeal 1.0 sealed connector system. The header (6473423-1) solders to the PCB at right angles; the plug (1473416-1) crimps onto the harness. 26 positions arranged in 4 rows (7-6-6-7), sealed to IP67 with silicone cavity seals and a secondary wedgelock. Contacts are gold-plated, rated for 16-18 AWG wire.

Assembly Instructions

Solder from lowest profile to highest. This keeps the board flat during soldering and prevents taller components from rocking the board.

Step 1 — Resistors

All resistors are axial through-hole. Bend leads 90° at the body, insert from the top, solder on the bottom, trim leads flush.

  • R1-R8 (4.7kΩ): Optional — install per-channel only for unpowered sensors. See note above.
  • R9-R16, R25-R26 (1kΩ): Gate resistors for MOSFETs and current-limiting for optocoupler LEDs.
  • R17-R24, R27-R28 (10kΩ): Pull-down resistors for MOSFET gates (ensure off-state).
  • R29 (120Ω): CAN bus termination — install only at bus endpoints.

Step 2 — Diodes

  • D1-D4 (1N5819 Schottky): Flyback diodes across inductive loads (fans, pumps, relays). Observe polarity — the stripe (cathode) goes toward the positive side of the load. These protect the MOSFETs from back-EMF.
  • D5-D8 (1N4148 signal): Signal diodes for optocoupler input protection. Observe polarity — stripe toward the optocoupler LED anode side.

Step 3 — Capacitors

  • C1-C8, C10 (0.1µF X7R): Decoupling caps for each MOSFET gate and optocoupler channel. Place close to the component they decouple. Non-polarized — orientation doesn't matter.
  • C9 (220µF hybrid, 50V): Bulk filter cap for the buck converter input. Polarized — the negative stripe goes to ground. Check polarity twice before soldering.

Step 4 — Optocouplers (U2, U3)

PC817 optocouplers isolate 12V detect inputs from the Nano's logic level. The 4-DIP package has a notch or dot on pin 1. Orient the notch toward the silkscreen indicator. The LED side (pins 1-2) faces the 12V input; the transistor side (pins 3-4) faces the Nano.

Ground separation: The optocoupler's LED side ground must go to the 12V/sensor ground, not the Nano's logic ground. The whole point of the optocoupler is galvanic isolation — bridging the grounds defeats it. Check that the input-side and output-side grounds are not connected on the board except through the optocoupler itself.

Step 5 — MOSFETs

  • Q1-Q4 (IRLZ44N, TO-220): High-current PWM outputs (fans, pumps, relays). Logic-level gate — driven directly from the Nano's PWM pins through 1kΩ gate resistors. Mount with heatsink tab facing the board edge for airflow. The pin order is Gate-Drain-Source from left to right (flat side facing you).
  • Q5-Q8 (BS170, TO-92): Low-current switches. TO-92 package — orient flat side per silkscreen. Pin order is Drain-Gate-Source (check datasheet — varies by manufacturer). These drive lower-load devices.

Step 6 — CAN Transceiver (J4)

SN65HVD230 or equivalent. This module mates with the Nano's CAN_TX (D5) and CAN_RX (D4) pins. The 120Ω termination resistor (R29) goes across CANH and CANL — install only if this is the last node on the bus.

Step 7 — Buck Converter (U1)

12V-to-5V step-down for the Nano. Solder or screw-terminal per the module's footprint on the board. The 220µF cap (C9) filters the input side. Verify 5V output with a meter before plugging in the Nano.

Step 8 — SuperSeal Header (J1)

Solder the 6473423-1 right-angle header to the board. The 90° pins go through the PCB; the mating face points outward for the harness plug. This is the tallest component — solder it last so the board sits flat for earlier steps.

Step 9 — Nano R4

Seat the Nano R4 in its headers (or solder directly, depending on board design). Confirm CAN pins D4/D5 align with the transceiver. Power up and verify 5V rail before connecting any loads.

Step 10 — Harness Crimping

  1. Strip 16-18 AWG wire ~6-7mm.
  2. Crimp the 3-1447221-3 gold socket contacts using a TE-approved crimp tool (the datasheet lists compatible tools).
  3. Insert crimped contacts into the 1473416-1 plug housing, matching the pinout table above. Listen for the click — the contact latch engages the wedgelock.
  4. Insert the secondary wedgelock (TPA) to lock all contacts in place.
  5. Install 4-1437284-3 sealing plugs in any unused cavities — every cavity must be filled to maintain the IP67 seal.
Unused cavities: Even if a pin isn't wired, a sealing plug must go in that cavity. An open cavity breaks the environmental seal and allows moisture into the connector.
