R1–R8 (4.7kΩ): Optional — external pullup resistors for sensors that need them. Leave unpopulated if using the Nano's internal pulls or if sensors provide their own.

R29 (120Ω): CAN bus termination resistor. Populate only if this node is at the physical end of the CAN bus. If it's a mid-bus node, leave it off.

Engine Ground (pins 23, 24, 25) — current-carrying return path. These three wires connect to the same ground point as the main ECU ground and the engine block. They complete the power loop back to the alternator. They carry the full return current for the 5A PWM outputs. Use adequate wire gauge (16 AWG minimum) and route to the same grounding point as the ECU.

Sensor Ground (pin 6) — zero reference only. NOT a power ground. This is the clean ground reference for the analog sensors. It does not carry current — it exists so the Nano's ADC has a stable 0V reference. Do NOT tie sensor ground to the engine ground (pins 23-25). Do NOT tie it to the ECU power ground. Keeping these separate is what prevents PWM switching noise from corrupting analog sensor readings.

Assembly Instructions

Solder from lowest profile to highest. This prevents taller components from getting in the way while you work.

Step 1 — Resistors

Install all resistors first — they're the flattest parts. Bend leads 90° at the body, insert through the holes, solder, and clip the leads flush.

  • R9–R16, R25–R26 (1kΩ) — gate resistors for MOSFETs and optocoupler limit resistors
  • R17–R24, R27–R28 (10kΩ) — pull-down resistors for MOSFET gates
  • R29 (120Ω) — CAN termination. Only if this is an end-of-bus node.
  • R1–R8 (4.7kΩ) — optional sensor pullups. Populate only if needed.

Step 2 — Diodes

Watch polarity — the stripe on the diode matches the stripe on the silkscreen.

  • D1–D4 (1N5819 Schottky) — flyback diodes across the IRLZ44N MOSFET outputs (inductive loads)
  • D5–D8 (1N4148) — signal diodes for the BS170 switch outputs

Step 3 — Capacitors

  • C1–C8, C10 (0.1µF ceramic) — decoupling caps. Place close to each IC and MOSFET.
  • C9 (220µF hybrid polymer) — main power filter cap. Mind polarity — the stripe side is negative.

Step 4 — Optocouplers (U2, U3)

Install the two PC817 optocouplers. These are 4-DIP packages — orient the dot/notch on the IC to match the silkscreen. The input side (LED) faces the connector; the output side (phototransistor) faces the Nano.

Step 5 — MOSFETs

  • Q1–Q4 (IRLZ44N, TO-220) — high-current PWM switches. Heatsink tab faces away from the board center. These carry up to 5A — ensure good solder joints on the source and drain pins.
  • Q5–Q8 (BS170, TO-92) — low-current switches. Orient the flat side per the silkscreen outline.

Step 6 — Buck Converter (U1)

Solder the buck converter module to the board. Input side receives 12V from pin 5; output side provides 5V to pin 12 and the Nano's 5V rail.

Step 7 — CAN Transceiver

Install the CAN transceiver (SN65HVD230 or equivalent). This connects to the Nano's D4 (CAN_TX) and D5 (CAN_RX) on the board side, and to pins 10 (CAN L) and 16 (CAN H) on the connector side. R29 (120Ω) terminates the bus if populated.

Step 8 — SuperSeal Header (J1)

Solder the 26-pin SuperSeal header (6473423-1) to the board. It's a right-angle surface-mount part with molded gold pins. Ensure it sits flush against the board before soldering all pins. This is the largest and tallest component — do it last among the board-side parts.

Step 9 — Arduino Nano R4

Install female headers for the Nano if not pre-populated, then seat the Nano R4. Pin mapping:

Nano PinBoard Function
A0–A7Sensor inputs (pins 1, 2, 8, 9, 14, 15, 20, 21)
D2, D712V/frequency detect via optocouplers (pins 3, 22)
D3, D6, D9, D105A PWM outputs via IRLZ44N (pins 7, 13, 19, 26)
D8, D11, D12, D130.5A switch outputs via BS170 (pins 4, 11, 17, 18)
D4, D5CAN_TX / CAN_RX — native CAN controller (pins 10, 16 via transceiver)
D0, D1Not broken out to connector (hardware serial / debug)

Step 10 — Harness Assembly

Crimp the 16-18 AWG gold sockets (3-1447221-3) onto your harness wires and insert them into the SuperSeal plug housing (1473416-1) according to the pinout above. Fill any unused cavities with sealing plugs (4-1437284-3) to maintain the IP67 rating.

The harness-side plug is keyed to match the 3-key header. When crimping, use the correct TE tool or a compatible universal crimp tool — a poor crimp will fail under vibration and heat cycling.
